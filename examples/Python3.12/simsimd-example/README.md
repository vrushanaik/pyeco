## Purpose: Demonstrates hardware-accelerated vector similarity computations using the SimSIMD library.

### Packages used:
simsimd, numpy

### Functionality:

- Computes cosine distance between two float32 vectors.
- Computes inner (dot) product.
- Computes squared Euclidean (L2) distance.
- Verifies results against NumPy reference values.
- Runs batch pairwise cosine distance over multiple query vectors.

### How to run the example:
```
chmod +x install_test_example.sh
./install_test_example.sh
```
