## Purpose: Demonstrates automatic CSV dialect detection and parsing using the CleverCSV library.

### Packages used:
clevercsv

### Functionality:

- Auto-detects the delimiter of a standard comma-delimited CSV.
- Auto-detects the delimiter of a semicolon-delimited CSV.
- Auto-detects the delimiter of a tab-delimited file with quoted fields.
- Reads rows from a detected CSV file using the clevercsv wrappers module.

### How to run the example:
```
chmod +x install_test_example.sh
./install_test_example.sh
```
