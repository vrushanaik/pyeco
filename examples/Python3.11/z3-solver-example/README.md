## Purpose: Demonstrates constraint satisfaction and satisfiability solving using the z3-solver library.

### Packages used:
z3-solver

### Functionality:

- Solves a two-variable arithmetic constraint (x + y = 10, x - y = 4).
- Finds all integers in a range satisfying a quadratic bound.
- Solves a simple task-scheduling puzzle with all-different constraints.

### How to run the example:
```
chmod +x install_test_example.sh
./install_test_example.sh
```
